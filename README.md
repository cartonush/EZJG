# EZJG · מאתר מכלולים

גרסה נוכחית: **1.1.3**.

## ניהול גרסאות

בכל עדכון מעלים את מספר ה־patch באחד. לאחר `1.0.9` מעלים את מספר ה־minor ומאפסים patch: `1.0.9` → `1.1.0`.

אב טיפוס PWA לחיפוש מכלולים לפי פאנל או לפי מערכת. כל השמות, המספרים והנתונים שבמאגר הראשוני מומצאים לצורכי הדגמה בלבד.

## שימוש

- פרסמו את המאגר דרך GitHub Pages או שרת סטטי תומך HTTPS.
- בחרו חיפוש לפי פאנל או לפי מערכת, בחרו ערך ואז מכלול כדי לראות מערכת, פאנל, כרך ו־JG.
- בשורת המשימות פתחו **מערכות / פאנלים**. בתוך הדף אפשר לעבור ישירות בין שתי הבחירות. מחוות הגדלה אינן פעילות בממשק הנייד.
- מתוך פרטי מכלול אפשר לפתוח את דף המערכת או את דף הפאנל המשויכים אליו.
- בשורת המשימות בחרו **קודים / ביקורות**. הלשוניות **ברק 1** ו־**ברק 2** מחליפות במקום את הטבלה, המציגה קוד ואת הביקורת של הדגם שנבחר.

## קובץ הנתונים

`data/טבלת_מכלולים_לדוגמה.xlsx` הוא קובץ הנתונים הראשי שהאפליקציה טוענת כברירת מחדל. גיליון **נתונים** נמצא ראשון ומכיל את שש העמודות. הקובץ `data/sample-data.csv` משמש כגיבוי אם Excel או ספריית הקריאה אינם זמינים.

`data/קודים_קשיחים.xlsx` הוא גיליון נפרד לעריכת קודים, עם העמודות **קוד**, **ברק1**, **ברק2**. הוסיפו כל קוד בשורה חדשה מתחת לכותרות. `data/hard-codes.csv` הוא גיבוי; אם ספריית Excel אינה זמינה, עדכנו גם אותו כדי ששתי התצוגות יהיו זהות.

## פרסום ב־GitHub Pages

המאגר כולל workflow שמפרסם את האתר בכל push ל־`main`. אם נדרש, הפעילו ב־GitHub: **Settings → Pages → Build and deployment → GitHub Actions**. לאחר הפרסום הכתובת תהיה בדרך כלל `https://cartonush.github.io/EZJG/`.

## מבנה

- `index.html`, `styles.css`, `editor.css`, `app.js` — ממשק RTL מותאם לנייד.
- `manifest.webmanifest`, `service-worker.js`, `assets/icon.svg` — תמיכה בהתקנה ושימוש בסיסי ללא רשת.
- `data/` — קבצי נתוני הדגמה.

## גבולות אב הטיפוס

אין כאן התחברות, הרשאות, שרת או מידע אמיתי. אין להזין מידע מסווג/מבצעי. קריאת Excel נעזרת בספריית SheetJS מ־CDN.
