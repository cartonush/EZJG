# EZJG · מאתר מכלולים

אב טיפוס PWA לחיפוש מכלולים לפי פאנל או לפי מערכת. כל השמות, המספרים והנתונים שבמאגר הראשוני מומצאים לצורכי הדגמה בלבד.

## שימוש

- פרסמו את המאגר דרך GitHub Pages או שרת סטטי תומך HTTPS.
- בחרו חיפוש לפי פאנל או לפי מערכת, בחרו ערך ואז מכלול כדי לראות מערכת, פאנל, כרך ו־JG.
- פתחו את לשונית **טבלה** כדי לערוך שדות, להוסיף או למחוק שורות, ולייצא את הטבלה לקובץ Excel.
- טענו קובץ Excel דרך כפתור **טעינת Excel** או לשונית **טבלה**. האפליקציה קוראת את הגיליון הראשון.
- הקובץ חייב לכלול כותרות מדויקות: `מכלול`, `מערכת`, `פאנל`, `כרך`, `JG`, `מסחא`.
- נתונים שנטענו נשמרים ב־localStorage של אותו דפדפן/מכשיר. אין כרגע סנכרון בין משתמשים.
- עריכה מתוך האפליקציה נשמרת בדפדפן המקומי; הורידו Excel כדי להעביר את העדכון לקובץ שב־GitHub.

## קובץ הנתונים

`data/טבלת_מכלולים_לדוגמה.xlsx` הוא קובץ הנתונים הראשי שהאפליקציה טוענת כברירת מחדל. גיליון **נתונים** נמצא ראשון ומכיל את שש העמודות. אם עורכים את הקובץ ושומרים את העדכון ב־GitHub, האתר יטען את הנתונים החדשים לאחר רענון. אפשר גם לטעון קובץ Excel מהמכשיר; הטבלה האישית נשמרת מקומית באותו דפדפן. הקובץ `data/sample-data.csv` משמש כגיבוי לטעינת נתוני הדגמה אם Excel/ספריית הקריאה אינם זמינים.

## פרסום ב־GitHub Pages

המאגר כולל workflow שמפרסם את האתר בכל push ל־`main`. אם נדרש, הפעילו ב־GitHub: **Settings → Pages → Build and deployment → GitHub Actions**. לאחר הפרסום הכתובת תהיה בדרך כלל `https://cartonush.github.io/EZJG/`.

## מבנה

- `index.html`, `styles.css`, `editor.css`, `app.js` — ממשק RTL מותאם לנייד.
- `manifest.webmanifest`, `service-worker.js`, `assets/icon.svg` — תמיכה בהתקנה ושימוש בסיסי ללא רשת.
- `data/` — קבצי נתוני הדגמה.

## גבולות אב הטיפוס

אין כאן התחברות, הרשאות, שרת או מידע אמיתי. אין להזין מידע מסווג/מבצעי. טעינת Excel נעזרת בספריית SheetJS מ־CDN, ולכן טעינת קובץ Excel דורשת חיבור אינטרנט. נתוני ההדגמה שכבר נטענו נשמרים זמינים מקומית.
